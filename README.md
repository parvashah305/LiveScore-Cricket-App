# Live Cricket Score

## Description

Live Cricket Score is a web application that provides real-time updates on ongoing cricket matches using the Cricbuzz API. Users can view detailed scorecards and match summaries.

## Features

- Real-time cricket score updates
- Match summaries and detailed scorecards
- Interactive UI with 'Show Details' feature

## Tech Stack

- **Frontend:** React, Tailwind CSS
- **API:** Cricbuzz API

## Installation & Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/LiveCricketScore.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm start
   ```
